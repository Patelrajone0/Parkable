# Git Commit Workflow

- **Automatic Commits**: Always automatically commit code changes to the `main` branch after completing requested features, fixes, or modifications.
- **Push to Remote**: Automatically push commits to `origin main`.
- **Commit Messages**: Use clean, descriptive conventional commit messages (e.g., `feat: ...`, `fix: ...`, `chore: ...`).
- **Clean Tree**: Ensure the working tree is kept clean and all relevant modified and new files are staged and committed.
